# 보고 대기 번호표 (Vercel만 사용)

국장님 보고 대기 번호를 휴대폰으로 받고, 차례가 오면 푸시 알림을 받는 설치형 웹앱입니다.
**Firebase가 필요 없습니다.** GitHub, Vercel, 그리고 Vercel 화면에서 붙이는 무료 저장소(Upstash Redis)만 씁니다.

| 구성 | 하는 일 | 비용 |
|---|---|---|
| GitHub | 코드 보관 | 무료 |
| Vercel (Hobby) | 화면과 서버(`/api`) 실행 | 무료 |
| Upstash Redis | 번호표와 설정 저장. Vercel → Storage에서 연결 | 무료 (월 50만 명령, 256MB, 카드 필요 없음) |
| 웹 푸시 | 휴대폰 알림. 브라우저 기본 기능이라 별도 서비스 없음 | 무료 |
| 구글 캘린더 | iCal 주소로 국장님 일정 읽기 | 무료 |

---

## 1. GitHub에 올리기 (기존 저장소 덮어쓰기)

1. GitHub에서 기존 저장소(numberbot)를 엽니다.
2. **예전 파일 중 지울 것:**
   - `api/` 폴더의 옛 파일
   - `lib/firebase.js`
   - `public/js/api-firebase.js`
   - `tests/fake-firebase.mjs`

   파일을 열고 오른쪽 위 `…` → **Delete file**을 누릅니다.
3. **Add file → Upload files**를 누릅니다. 이 압축 안의 파일과 폴더를 모두 끌어다 놓고 **Commit changes**를 누릅니다.
   - 이때 올릴 것: `api`, `lib`, `public`, `tests`, `package.json`, `vercel.json`, `README.md`
4. Vercel이 연결되어 있으면 자동으로 다시 배포됩니다.

> 이 상태로 사이트를 열면 아직 **데모 모드**입니다. 화면 위쪽에 "저장소 연결 전"이라고 나옵니다. 2단계를 마치면 실제 운영으로 바뀝니다.

## 2. 무료 저장소 연결 (Upstash for Redis)

1. Vercel 대시보드 → 프로젝트(numberbot) → 위쪽 **Storage** 탭을 엽니다.
2. **Create Database** (또는 Marketplace) → **Upstash** → **Upstash for Redis**를 고릅니다.
3. 요금제는 **Free**, 지역은 **Tokyo(ap-northeast-1)**처럼 가까운 곳을 고른 뒤 만듭니다.
4. 이 프로젝트에 **Connect**합니다. 환경 변수 `KV_REST_API_URL`과 `KV_REST_API_TOKEN`이 자동으로 들어갑니다.

## 3. 관리자 비밀번호 정하기 (환경 변수)

Vercel → 프로젝트 → **Settings → Environment Variables**에서 아래 값을 추가합니다.

| 이름 | 값 | 필수 |
|---|---|---|
| `ADMIN_PASSWORD` | 비서실이 쓸 관리자 비밀번호 (길게) | 필수 |
| `ACCESS_CODE` | 처음 접수 코드. 비우면 `1234`이고, 나중에 관리 화면에서 바꿀 수 있습니다 | 선택 |
| `CRON_SECRET` | 아무 긴 문자열. 5단계 외부 예약을 쓸 때 주소가 유출되지 않게 막습니다 | 선택 |

값을 넣은 뒤 **Deployments → 맨 위 배포 `…` → Redeploy**를 눌러야 적용됩니다.

> 비밀번호 같은 비밀 값은 **GitHub에 절대 올리지 말고** 여기(Vercel 환경 변수)에만 넣으세요.

## 4. 관리 화면에서 마무리

1. `https://numberbot-six.vercel.app/admin.html`을 열고 관리자 비밀번호로 로그인합니다. 로그인은 이 기기에서 30일 동안 유지됩니다.
2. **운영 설정 → 국장님 캘린더**를 정합니다.
   - 캘린더가 **공개**라면: 캘린더 ID(`rdarndpolicy@gmail.com`)만 있으면 됩니다.
   - 캘린더가 **비공개**라면: 구글 캘린더 → 설정 → 그 캘린더 → **캘린더 통합** → **iCal 형식의 비밀 주소**를 복사해 넣습니다. 이 주소는 관리 화면에만 보입니다.
3. **접수 코드**를 바꾸고 저장합니다.
4. **접수 안내 QR**을 인쇄해 국장실 앞에 붙입니다. 이 QR로 들어오면 접수 코드가 자동으로 입력됩니다.
5. "오늘 국장님 일정"에서 **지금 다시 읽기**를 눌러 일정이 맞게 나오는지 확인합니다.

## 5. (선택) 1분마다 확인 — cron-job.org

서버는 누군가 앱이나 관리 화면을 열어 두고 있으면 10~15초마다 스스로 다음 일을 합니다.

- 호출
- 재알림
- 5분 초과 취소
- 캘린더 확인

**비서실에서 관리 화면을 켜 두면 추가 설정은 필요 없습니다.**

아무도 화면을 켜 두지 않는 시간에도 정확히 돌게 하려면 [cron-job.org](https://cron-job.org)(무료)에 작업을 하나 만듭니다.

- URL: `https://numberbot-six.vercel.app/api/tick?key=CRON_SECRET값`
- 주기: 매 1분

(Vercel 무료 요금제의 자체 예약은 하루 1번뿐이라 새벽 정리용으로만 씁니다.)

## 어떻게 동작하나요

- **번호표:** 순서만 정합니다. 보고 시간은 참고용입니다.
  - 예상 시각은 실제 "보고 시작~완료" 평균으로 계산합니다. 처음에는 10분으로 봅니다.
- **자동 호출:**
  - 앞 사람이 **보고 완료**를 밀면 다음 사람을 호출하고, 그다음 사람에게 "문 앞 대기" 알림을 보냅니다.
  - 호출 후 3분이 지나면 재알림을 보냅니다.
  - 5분 안에 **보고 시작**을 누르지 않으면 번호표가 자동 취소되고 다음 사람을 호출합니다.
- **캘린더:** 국장님 일정이 있는 시간, 그리고 일정이 끝난 뒤 5분까지는 호출하지 않습니다. 접수는 계속 받습니다.
  - 종일 일정은 호출을 막지 않습니다.
  - 캘린더는 5분마다 다시 읽습니다.
- **시간 지정:** 정한 시각이 되면, 지금 보고 중인 분 바로 다음 차례가 됩니다. 관리 화면에서 켜고 끌 수 있습니다.
- **보고 가능 시간:** 기본 07:00~24:00입니다. 관리 화면에서 바꿀 수 있습니다.
- **개인정보:** 신청자 화면에는 가린 이름(고*래)과 부서만 나옵니다.
  - 실명과 건명은 관리 화면에만 보입니다.
  - 매일 자정이 지나면 실명, 건명, 일정 제목, 알림 기록을 지웁니다.
  - 가린 기록은 90일 뒤 자동으로 삭제됩니다.
- **알림:**
  - 안드로이드는 크롬에서 바로 알림을 받을 수 있습니다.
  - 아이폰은 Safari → 공유 → **홈 화면에 추가**로 설치한 앱에서만 알림을 받을 수 있습니다(iOS 16.4 이상).
  - 처음 한 번 **테스트 알림**을 받아야 번호표를 받을 수 있습니다. 관리 설정에서 이 조건을 끌 수 있습니다.

## 무료 한도는 괜찮나요

- 앱을 하루 종일 10초마다 조회해도 Redis 명령은 하루 약 7천 개입니다. 한 달이면 약 22만 개로, 무료 50만 개 안에 들어갑니다.
- 여러 사람이 동시에 봐도 Vercel 캐시 덕분에 10초에 한 번만 계산합니다.
- 화면을 끄면 조회도 멈춥니다.

> Vercel Hobby 요금제는 개인·비상업 용도 기준입니다. 기관 차원의 공식 사용이라면 약관을 확인해 주세요.

## 폴더 구조

```
api/op.js        앱이 부르는 기능 (번호표 · 시작 · 완료 · 관리자 기능)
api/state.js     공개 현황 (10초 캐시 · 호출 판단 겸함)
api/tick.js      예약 작업용 (선택)
lib/server.js    서버 동작 (저장 · 잠금 · 푸시 · 캘린더)
lib/redis.js     Upstash Redis 연결
lib/webpush.js   표준 웹 푸시 (암호화 + VAPID 서명)
lib/ical.js      구글 캘린더 iCal 읽기 (반복 일정 포함)
public/          화면 (신청자 index.html · 관리 admin.html · 규칙 js/logic.js)
tests/           자동 테스트: npm test (24개)
```

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 계속 "데모 모드" | 2단계 Storage 연결 후 **Redeploy**를 했는지 |
| 관리자 로그인 안 됨 | `ADMIN_PASSWORD`를 넣고 Redeploy 했는지. 20번 틀리면 1시간 동안 막힙니다 |
| 캘린더 "연동 문제" | 캘린더가 공개인지 확인하거나, 비밀 주소(iCal)를 넣었는지 |
| 알림이 안 옴 | 휴대폰 설정에서 알림을 허용했는지. 아이폰은 홈 화면 앱으로 열었는지 |
| 관리 화면에 "알림 실패" | 그분 휴대폰 알림이 꺼졌거나 앱을 지운 경우입니다. 직접 불러 주세요 |
